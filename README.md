# Google Flow Reverse Engineer & Nursery Rhyme Video Pipeline

Automated generative AI nursery rhyme pipeline with dynamic scene pacing (4s-10s), character continuity anchoring, and frame-chained video generation.

## Quick Start (Windows)
Double-click \un.bat\ or run in terminal:
\\\cmd
run.bat
\\\

## Architecture
- \server.py\: Fast local engine bridge exposing /api/v1 video endpoints.
- \dynamic_rhyme_pipeline.py\: Intelligent rhyme lyric parser, character binder, and frame continuity chaining runner.
